# docs

综述正文、参考文献与阅读笔记。

## 写作约定

- **一节一个文件**，文件名带两位序号，便于按顺序拼接
- 每节开头先用三到五条列出"本节要回答的问题"，写完后逐条划掉；没划掉的说明还没写完
- 所有引用统一进 `refs/references.bib`，正文里只用 `[@key]`
- 任何数量级论断（"锁数量减少一个数量级"）必须能指回 `experiments/results/` 的具体文件
- 不确定的猜想放 `notes/`，不要混进正文；验证之后再挪进去

## 目录

| 目录 | 用途 |
|---|---|
| `survey/` | 综述正文，按章节拆分 |
| `refs/` | BibTeX 文献库 |
| `notes/` | 阅读笔记、设计讨论、待验证猜想 |
